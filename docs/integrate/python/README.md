# Integrate Python applications with StatLite

StatLite supports lightweight, application-owned integrations for common Python
web frameworks.

| Framework | Integration guide | Runnable example |
| --- | --- | --- |
| FastAPI | [FastAPI guide](fastapi.md) | [FastAPI demo](../../../examples/python-fastapi-demo/) |
| Django | [Django guide](django.md) | [Django demo](../../../examples/python-django-demo/) |

Each guide includes a small helper and middleware you can copy into your
application to expose `GET /statlite/metrics`. No StatLite SDK or additional
third-party runtime dependency is required.

See the [integration index](../README.md) for other integrations.
